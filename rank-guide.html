// ランク上げガイド

序盤〜終盤の動き方、立ち回りの考え方をまとめています。

⚠️ 注意：このページの内容はAI（Claude）を活用して作成されています。情報の正確性は各自でご確認ください。
📝 サイト制作者より：このサイトに掲載されているキャラ対策・立ち回りの内容は、制作者個人のプレイ経験・主観に基づく意見を多く含みます。ゲームのバランス変更や環境の変化により内容が古くなっている場合があります。あくまで参考程度にお使いください。
💡 ランクを上げる上で最も大切なのは「勝てる戦いだけをする」こと。無謀な戦いを避け、有利な状況を作ってから動くことが安定したポイント獲得につながります。

▶ 序盤 (1〜5分)

  • クラフトを優先してアイテムを揃える
  • 野生動物で経験値とスタックを稼ぐ
  • 相手の位置をカメラで把握する
  • 無理な戦闘は避けて内政に集中
  • 飯（食料）を切らさない

▶ 中盤 (5〜15分)

  • チームと合流して人数有利を作る
  • ハイパーループで移動効率を上げる
  • 弱ったチームを狙って戦闘を仕掛ける
  • アルファ・オメガを意識して動く
  • カメラを積極的に設置して視界確保

▶ 終盤 (15分〜)

  • エリアが狭まるので位置取りを慎重に
  • 3チーム残っている時は漁夫を狙う
  • 無敵・CC無効スキルのタイミングを合わせる
  • 瀕死の敵を逃さず殺し切る
  • 最終エリアでの乱戦に備えて回復を温存

// 基本的な考え方

  • 人数有利で戦う。タイマンが強いキャラ以外は1v1を避けてチームで動く。
  • 体力有利がある状態で戦闘を仕掛ける。全快の相手にオールインしない。
  • 戦闘後はすぐ回復。次の戦闘に備えて常にHPを高く保つ。
  • 死なないことが最優先。キルよりも生存がポイントに直結する。
  • 弱った相手・少ない人数のチームを選んで戦う「選択眼」を磨く。

// 戦闘中の意識

  • 相手のスキルを把握してから戦う。無敵・CC無効持ちは特に要注意。
  • CCスキルは無駄撃ちしない。相手のCC無効・無敵に合わせない。
  • フォーカス（集中攻撃）を徹底する。チームで別々の敵を狙わない。
  • 乱戦は広がって戦う。AOEスキルに全員まとめて当たらない。
  • 瀕死の敵は必ず殺し切る。中途半端に残すと回復されて不利になる。
  • 後入りのキャラ（ジャッキー・シルヴィアなど）を乱戦中も意識し続ける。

// 立ち位置・マップ意識

  • 狭い場所はAOEキャラに有利。エリア掌握キャラがいる場合は広い場所を選ぶ。
  • 壁際は壁ドンキャラ（ヒョヌ・マーカスなど）に危険。壁に背を向けない。
  • 草むらはステルスキャラのキャッチ起点。カメラを積極的に活用する。ブッシュは３日目以降要注意、特に夜など。カメラが付いていればドローン・望遠カメラで確認。
  • エリア縮小を常に確認。安地の端に追い詰められると戦いにくくなる。

// キャラ選択の考え方

  • 自分が一番慣れているキャラを使う。強キャラより使い慣れたキャラの方が安定する。
  • チーム構成は火力が足りていれば問題ない。
  • 無敵・CC持ち・対象指定スキルなどあるキャラは安定しやすい。
  • 自衛手段が豊富なキャラは初心者にも扱いやすい（アヤ・ジェニーなど）。
